Run a digital-gardening round over Cam's SilverBullet space.

Invoke the `serendipity-gardening` skill and follow it; it carries the full workflow, the page
template, and the voice guide. Do not re-derive the steps from this file.

## Arguments

- `orphans` (optional): draw from orphaned / thinly-linked notes instead of the uniform random
  draw. Without it, use the Serendipity page's own `randomPage()` pickers.

The skill's hard rules apply: it writes exactly one file, the ephemeral session page, and never
edits Cam's content notes.
